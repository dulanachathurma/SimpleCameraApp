# Simple Camera App

A simple Android app built with Kotlin and Jetpack Compose for the Mobile Application Development assignment.

## Features
- Open the device camera
- Capture a photo
- Display the captured photo in the app
- Share the photo using the Android share sheet

## Concepts used
- Camera permission
- Camera access
- Intents
- FileProvider

## Tested on
Pixel 6 emulator (API 34)
