## Features
- Open the device camera
- Capture a photo
- Display the captured photo in the app
- Share the photo using the Android share sheet

## Concepts used
- Camera permission
- Camera access
- Intents
- FileProvider

## Tech stack
- Kotlin
- Jetpack Compose
- Android Studio

## Tested on
Pixel 6 emulator (API 34)
